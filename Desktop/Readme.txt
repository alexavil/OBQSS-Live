This Debian Rescue image includes the common recovery and utility tools, such as:
- TestDisk
- GParted (also supports NTFS, FAT and btrfs partitions)
- Falkon
- PCManFM
- Leafpad

Do not use this system as a full installation of Linux. All data will be lost on reboot, unless saved in a persistent storage (such as your local drives).
